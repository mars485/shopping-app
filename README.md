# Shopping

Family shopping list app. Mobile: React Native / Expo / TypeScript. Backend: FastAPI + PostgreSQL (separate production deployment).

API: https://shopping.karpiev.ru

## Clone on Windows

```powershell
cd D:\Projects
git clone https://github.com/mars485/shopping-app.git
cd shopping-app
```

Open this folder in OpenCode. See `AGENTS.md` and `docs/roadmap.md`.

**Status:** OpenCode project configuration committed. Existing mobile v0.3 source is not yet committed to this repository. APK not built. Never commit secrets or modify production without approval.
