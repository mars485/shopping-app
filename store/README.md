# Публикация в RuStore

Пакет материалов для загрузки в RuStore лежит в `store/`:

```
store/
  README.md              этот файл
  icon-512.png           иконка 512×512 для карточки приложения
  screenshots/           скриншоты телефона (1080×2400)
    01-sign-in.png       экран входа
    02-lists.png         список списков
    03-list-detail.png   детали списка: сумма, прогресс, товары
    04-item-editor.png   редактирование товара (количество, цена, единица)
    05-settings.png      настройки: сервер, версия, темы
    06-dark-theme.png    тёмная тема
  ru/
    metadata.json        версия, package, категория, рейтинг, контакты
    description.md       краткое и полное описание, ключевые слова
    whats-new.md         «Что нового»
```

## 1. Что загружать

| Параметр | Значение |
|---|---|
| Формат | APK (universal, arm64-v8a + armeabi-v7a + x86_64 + x86) |
| Файл | `mobile/dist/shopping-1.0.0-release.apk` |
| Package | `ru.karpiev.shopping` |
| Версия | `1.0.0` (`versionCode 1`) |
| minSdk / targetSdk | 24 (Android 7.0) / 36 |
| Подпись | постоянный upload-keystore `CN=Shopping` (SHA-256 `D8:3C:31:…:71:84`) |
| Размер | ~87 МБ |

Проверка перед загрузкой:

```powershell
& "D:\Tools\android-sdk\build-tools\37.0.0\apksigner.bat" verify --print-certs `
  mobile\dist\shopping-1.0.0-release.apk
& "D:\Tools\android-sdk\build-tools\37.0.0\aapt2.exe" dump badging `
  mobile\dist\shopping-1.0.0-release.apk | Select-String "package:|native-code"
```

`native-code` должен содержать `arm64-v8a` (требование RuStore к 64-битным сборкам).

## 2. Метаданные в консоли RuStore

Берутся из `store/ru/metadata.json`:

- **Название**: Shopping
- **Краткое описание** (до 80 символов): `store/ru/metadata.json → shortDescription`
- **Полное описание**: `store/ru/description.md`
- **Что нового**: `store/ru/whats-new.md`
- **Категория**: Покупки
- **Возрастной рейтинг**: 0+
- **Язык**: русский
- **Иконка**: `store/icon-512.png`
- **Скриншоты**: `store/screenshots/*.png` (телефон, 1080×2412)
- **Политика конфиденциальности**: ссылка на `docs/privacy-policy.md` (после публикации репозитория — GitHub Pages или raw-ссылка; текст нужно разместить по публичному URL)
- **Контакты поддержки**: e-mail из `metadata.json`

## 3. Доступ для модерации

Приложению нужен вход по e-mail и паролю, поэтому в консоли RuStore в поле «Данные для доступа» укажите тестовый аккаунт:

```
E-mail: review@karpiev.ru
Пароль: <создать отдельный пароль, не от личного аккаунта>
```

Аккаунт нужно предварительно зарегистрировать в приложении (или через API), чтобы модератор увидел готовый список. Не используйте личный аккаунт и не публикуйте пароль в репозитории.

## 4. Порядок публикации

1. Зарегистрировать аккаунт разработчика в RuStore Консоли, подтвердить организацию/ИП (по требованиям магазина).
2. Создать приложение, заполнить карточку (название, описания, категория, рейтинг).
3. Загрузить APK, дождаться проверки подписи и версии.
4. Заполнить «Данные для доступа» тестовым аккаунтом.
5. Приложить скриншоты и иконку.
6. Отправить на модерацию.

## 5. Обновления

- Перед каждой новой сборкой увеличивайте `versionCode` (и `version` при заметных изменениях) в `mobile/app.json`.
- Подписывайте тем же upload-keystore (`mobile/keystore.properties`, ключ вне репозитория) — иначе RuStore отклонит обновление.
- После релиза добавьте тег в git: `git tag v1.0.0 && git push --tags`.

## 6. Ограничения текущей версии

- Нет переименования списка и выхода из общего списка (нет эндпоинтов в API).
- Нет push-уведомлений и realtime-синхронизации: обновление по фокусу, pull-to-refresh и возврату в приложение.
- Нет рекламы, аналитики и трекеров — это отражено в политике конфиденциальности.
